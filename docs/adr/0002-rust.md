# Rust for the CLI

`bli` is written in Rust rather than Go, TypeScript on Bun, or Bash (the language of the scripts it replaces). We picked it for the small, fast-starting single binary and for traits that keep the lane host and issue tracker adapters honest. Raw speed was not the reason: nearly all of `bli`'s run time is spent waiting on `gh`, the lane host's CLI, or ClickUp's API.
